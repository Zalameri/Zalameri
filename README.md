# Hi, I'm Zainab Alameri

Computer Science & Artificial Intelligence student at Effat University. I build small, working projects
in Python and web technologies, and I care about tests, clear READMEs and fixing the bugs I find.

## Featured projects

**[StudyBuddy Flashcards](https://github.com/Zalameri/studybuddy-flashcards)** (Python, SQLite)
A command-line flashcard app that schedules reviews with the SM-2 spaced-repetition algorithm. The algorithm is a
small pure function that is covered by unit tests, and all SQL is parameterised.
[Tests](https://github.com/Zalameri/studybuddy-flashcards/tree/main/tests)

**[Smart Study](https://github.com/Zalameri/smart-study)** (HTML, CSS, JavaScript, PHP, MySQL)
A study-planning web app with accounts, courses, a weekly schedule, chapter notes and quizzes generated from
your own notes (English and Arabic). Engineering work so far: escaping user text before it reaches `innerHTML`
([PR #2](https://github.com/Zalameri/smart-study/pull/2)), a fix for an Arabic quiz freeze, and tests in JavaScript and PHP.
[Tests](https://github.com/Zalameri/smart-study/tree/main/tests)

**[Student Grade Tracker](https://github.com/Zalameri/Student-Grade-Tracker)** (Python)
A command-line program that totals quiz, midterm and final grades, reports pass or fail and summarises a class.
It validates input and has `pytest` tests.
[Tests](https://github.com/Zalameri/Student-Grade-Tracker/tree/main/tests)
